# auro-update

Signed update manifests, full/delta staging, deterministic rollout, platform apply/rollback paths (AppImage, MSI/NSIS,
`.app.zip`), and a durable apply journal with reconciliation/cleanup plus self-helper apply/restart handoff.

Part of [Auro](https://github.com/pdl-clay/auro), a native Rust desktop application framework
built on [GPUI](https://gpui.rs). This crate is pre-alpha; see the repository and the
[book](https://pdl-clay.github.io/auro/) for the current roadmap and documentation.
